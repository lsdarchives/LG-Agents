# Results

> **Stub: filled in at step 9 (CLI).** Until then this page only describes what will go here.

Once `python main.py "<task>"` works, every sample task in [03-tasks.md](03-tasks.md) is run through
the full graph, and the outcome is recorded here.

## What will be recorded

| Column | Meaning |
|---|---|
| Task | Which sample task (1–5) |
| Status | `success` or `max_iterations` |
| Iterations | How many coder attempts it took (`iteration` at the end) |
| Score | Passed tests for the final / best code (`best_score`) out of the total |
| Test-fix used | Whether the debugger blamed the tests and they were rewritten (`test_fix_used`) |
| LLM calls | Total model requests (relevant for free-tier daily quotas) |
| Notes | Anything notable: wrong tests, lint-only failures, timeouts |
